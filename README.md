📌 Project Overview
This project focuses on practical cybersecurity activities involving Footprinting, Open-Source Intelligence (OSINT), and Network Scanning.

As part of Week 2 cybersecurity training, I explored various tools, including theHarvester, Google Hacking Database (GHDB), Maltego, Nmap, and Zenmap, to understand information gathering, reconnaissance, and network analysis techniques.

The project involved collecting publicly available information, exploring domain-related data, identifying live hosts, analyzing network scanning results, and visualizing network topology.

It also includes practical task screenshots and a final penetration testing report documenting the activities, observations, and findings.

The main objective was to gain hands-on experience with reconnaissance methodologies and develop practical skills used in the initial phases of ethical hacking and penetration testing.
